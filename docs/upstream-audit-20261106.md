## 暂不合并

- `f5ed5eb8` 的 GPT Image 2.6 只涉及 Codex CPA 订阅模型目录，和 API-Load 的普通供应商转发无直接关系。
- Devin、Muse 和 OAuth 订阅更新会扩大凭据类型和外部登录流程，当前用户没有计划使用 OAuth 订阅，暂不引入。
- upstream 的 request body recording 需要新的迁移和长期保存请求体，涉及隐私、磁盘空间和兼容性，不能因为日志界面改进就默认开启。
- upstream 的 modern/classic 大规模界面重构会覆盖 API-Load 已有的透明转发和原生服务入口。需要 UI 改善时按组件局部移植。
- Bifrost 1.13.1、CPA embedded 和 `x/*` 依赖升级需要独立分支验证，不能和协议适配同时更新。重点检查 native speech、Responses、WebSocket 和透明转发回归。

## 后续维护规则

每次同步上游时先记录上游提交和本地主线提交，再按功能提交逐项比较。涉及协议、凭据、请求体、日志和存储的改动分别验证，确认迁移和恢复行为后再发布。上游主线只作为资料来源，不作为 API-Load 的生产基线。
